# Sistema de Contenido Audiovisual
## Descripcion
Este proyecto consiste en un sistema desarrollado en Java que permite gestionar contenidos audiovisuales como peliculas, series, documentales, videos de YouTube y cortometrajes.
Se aplican conceptos de Programacion Orientada a Objetos como herencia, encapsulamiento y uso de clases.

## Funcionalidades
* Crear y mostrar peliculas con actores
* Gestionar series de TV con temporadas
* Manejar documentales con investigadores
* Visualizar videos de YouTube y cortometrajes
* Guardar y leer datos desde archivos CSV

## Estructura del Proyecto
El proyecto está organizado en paquetes:
* model: clases principales del sistema
* controller: logica del sistema
* service: manejo de archivos
* view: interaccion con el usuario

## Tecnologias Utilizadas
* Java
* Eclipse IDE

## Ejecucion
1. Clonar el repositorio
2. Abrir el proyecto en Eclipse
3. Ejecutar la clase Main.java

## Funcionalidad de Archivos
Se implemento la lectura y escritura de archivos CSV mediante la clase ArchivoService, permitiendo guardar y recuperar informacion.
